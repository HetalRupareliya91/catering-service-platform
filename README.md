# Royal Feast Catering Platform

A complete catering service platform:

- **Backend API** - Node.js + Express REST API with a JSON file data store
- **Customer website** - menu, packages, venues, reviews and event booking
- **Admin panel** - manage all 14 modules, dashboard stats and reports
- **Mobile view** - responsive layouts, bottom navigation and installable PWA

## Modules

Categories, Menu Items, Packages, Venues, Events, Customers, Bookings, Staff,
Vendors, Inventory, Invoices, Payments, Reviews, Deliveries.

## Quick start

```bash
cd backend
npm install
npm run seed
npm start
```

- Website: http://localhost:4000
- Admin panel: http://localhost:4000/admin (default login `admin@catering.local` / `admin123`)

See `docs/setup.md` and `docs/architecture.md` for details.
